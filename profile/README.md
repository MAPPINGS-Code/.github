# MAPPINGS Family

**Welcome to the MAPPINGS Family organization.**

This organization contains various versions of the  **MAPPINGS code**

* Mappings3 is a working version, which was the primary version of the code during the period 1980 - 2015,  Ut us retained hre primarily to allow comparisons with newer versions of the code.  It should not be used for any new work.
* Mappings5 is the current version of the code.  It is the version that should be used today
* Mappings6 (which is currently an empty repository) is intended for the next generation of the code.
* M3 is a Monte Carlo radiative transfer code intended for modelling HII regions in 3D
